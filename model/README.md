# Model folder

Put your trained TensorFlow/Keras model here and name it:

```text
deepfake_model.keras
```

Or set a custom path before running the app:

```bash
export MODEL_PATH="/path/to/your/model.keras"
```

On Windows PowerShell:

```powershell
$env:MODEL_PATH="C:\path\to\your\model.keras"
```
